用 GitHub 身份进入

这个站点没有独立账号体系。身份由 GitHub 提供，仓库拥有者登录后自动获得管理权限。

纯静态站点无法在浏览器里完成 OAuth 回调，因此使用你本人的 GitHub 令牌作为身份凭证。 只需要该仓库的 Contents: Read and write 权限。

  1. 到 GitHub → Settings → Developer settings → Fine-grained tokens 生成令牌
  2. 勾选你的博客仓库，权限只给 Contents: Read and write
  3. 粘贴令牌登录；拥有者会直接看到「进入管理台」入口

令牌只存在当前标签页，关闭浏览器即失效，六小时后自动过期，不会写入仓库或磁盘。 非仓库拥有者的 GitHub 账号无法进入管理台。需要生成令牌？ 打开 GitHub。
