所有内容保存在仓库的 data/ 目录：site.json、posts.json、downloads.json。 也可以直接在 GitHub 网页上编辑这三个文件。

发布前检查

  • 仓库设置 → Pages → Source 选择当前分支的根目录。
  • 仓库根目录保持存在 .nojekyll 文件。
  • 令牌仅授予该仓库 Contents 读写权限，用完可在 GitHub 上吊销。
  • 站内文件放在 files/，路径填写相对路径，例如 files/tool.zip。
